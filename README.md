# Portafolio de Demos — Edwin

Repositorio con proyectos demo que muestran mis habilidades en automatización, desarrollo móvil y análisis de datos.

## Demos incluidos

### 1. Automatizador de Reportes con Python
Limpia datos de un CSV, calcula métricas y genera un reporte en PDF con gráficas.

- **Tecnologías:** Python, pandas, matplotlib, reportlab
- **Estado:** ✅ Funcionando

### 2. App de Gastos Personales con Flutter
Aplicación móvil y web para registrar gastos, ver totales y gráficas por categoría.

- **Tecnologías:** Flutter, Dart, fl_chart, intl
- **Estado:** ✅ Funcionando

### 3. App Dashboard con Flutter
Panel con tarjetas de métricas y gráficas para visualizar datos de negocio.

- **Tecnologías:** Flutter, Dart, fl_chart, intl
- **Estado:** ✅ Funcionando
