# Demo 2 — Dashboard de Ventas en Flutter

Aplicación web tipo panel de control con métricas de ventas, gráfico de barras y actividad reciente.

## Cómo probarlo

1. Abre una terminal en esta carpeta.
2. Ejecuta:
   ```bash
   flutter run -d chrome
   ```
   O sirve la versión compilada en `build/web/` con cualquier servidor estático.

## Estructura

- `lib/main.dart` — UI completa del dashboard.
- `build/web/` — versión compilada lista para desplegar.

## Funcionalidades mostradas

- Layout responsive con `NavigationRail`.
- Tarjetas de métricas con cambios porcentuales.
- Gráfico de barras custom sin librerías externas.
- Lista de actividad reciente.
