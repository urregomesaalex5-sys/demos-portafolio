# Demo 2 — App de Gastos Personales (Flutter)

Aplicación móvil y de escritorio para registrar gastos diarios, ver el total acumulado y distribuir los gastos por categoría en una gráfica.

## Funciones

- Agregar gastos con concepto, monto y categoría.
- Ver total gastado en tiempo real.
- Gráfica circular (pie chart) por categoría.
- Lista de movimientos con fecha.

## Tecnologías

- Flutter 3.x
- Dart
- `intl` para formato de moneda y fechas
- `fl_chart` para la gráfica

## Cómo ejecutar

```bash
cd gastos_personal
flutter pub get
flutter run
```

Para Windows:

```bash
flutter run -d windows
```
